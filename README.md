# hey, i'm Indica 👋

Developer behind **Strata** — a modular FiveM framework built from the ground up.

---

### what i'm working on

- 🔧 **Strata Framework** — a modular FiveM framework with 45+ first-party resources, a shared library, consistent UI across every system, and a full modern NUI stack
- 🌐 **stratafw.com** — the framework site, built with Next.js 16, Tailwind CSS v4 and deployed on Vercel
- 🤖 **Strata Bot** — a custom Discord bot built for RP servers running on the framework
- 🖥️ **Web Panel** — a player-facing dashboard synced with the framework for analytics, player management and queue
